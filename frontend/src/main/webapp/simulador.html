Simulador de microcontroladores

Envía lecturas secuencialmente al backend como si fueran sensores físicos.
WebSocket desconectado

Configuración

Crear sensor

Al crear un sensor, se registra en /api/sensores y se incorpora automáticamente a la secuencia.

Secuencia

Solo se envía una lectura por turno. Con 4 sensores y 2000 ms, cada sensor recibe una lectura aproximadamente cada 8 segundos.

Sensores simulados

El estado cambia automáticamente a INACTIVO cuando el backend detecta que dejó de recibir lecturas.
Secuencia detenida
Para ejecutar esta página sin problemas de CORS, colócala en frontend/src/main/webapp/simulador.html y abre http://localhost:8081/monitoreo/simulador.html.
